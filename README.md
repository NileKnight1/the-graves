# The Graves Keeper
 A 2d game made with godot.

## Gameplay:
 You spawn in a graves place, you have to keep the place safe, there're
4 sectors each with a camera, you have to guard the place and detect
anomalies, things moving, things disappearing, new things appearing!
then you report it to the radio and it's get fixed, but be careful,
if you report wrong 3 times you lose, and if danger exceeds the limit
you lose, danger is calculated by count of non-reported anomalies at each
second. You'll face event throughout your shifts, cameras sabotaged, 
generator getting stolen, and more! You'll meet Dracula and Frankenstein!
The newspaper might help you 🦜.

## Controls:
- A/D -> left/right
- Space -> Jump (not useful lol)
- Shift -> sprint
- E -> interact

## Devices:
- Playable on browser supporting touch and non-touch devices
